# TP3 : Jeu du pendu

> Un **mot** est **choisit aléatoirement** depuis un [fichier de mots](resources/words.csv), le but est de deviner le mot en proposant une **lettre** ou un **mot complet**.

Le joueur peut proposer :

- **une lettre**, si la lettre est **dans le mot**, elle est **révélée** __sinon__, il **perd une vie**.
- **un mot complet**, si le mot est **correct**, il **gagne** __sinon__, il **perd instantanément**.

Au début du jeu, le joueur a **8 vies**, lorsqu'il lui reste **0 vies**, il **perd la partie**.
